# Mapa de muebles

```
Escritorio → Tablero → Archivador
Escritorio → Hábitos
Escritorio → Mesa de análisis
Diario (no sale nunca)
Biblioteca (recibe conocimiento — reservado)
Finanzas (recibe registros — reservado)
```

Una hoja nunca cambia de identidad. Solo cambia de lugar.
Cada mueble tiene una única función.
Mover nunca significa borrar.
Todo tiene un hogar.
