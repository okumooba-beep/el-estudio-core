# Mapa del mundo

```
Muro de Proyectos — Escritorio — Ventana — Rincón de Lectura — Biblioteca
```

Cada lugar existe aunque todavía no tenga pantalla.
La cercanía es real, no decorativa: no describe qué pantalla sigue a cuál, describe qué queda al lado de qué.
Un lugar no nace porque una pantalla lo necesita. Nace porque el cuarto ya lo contiene.
El mapa es parcial a propósito — crece cuando el mundo lo confirma, no cuando el código lo apura.
