## 1. Qué es El Estudio

El Estudio es un lugar, no una aplicación. Es el sitio al que una persona
vuelve cada día para construir su vida — no una herramienta que se abre
cuando hace falta y se cierra cuando no.

La diferencia es literal, no de marketing: una app se anuncia, pide
permisos, celebra logros y notifica cuando el usuario no está. El Estudio
nunca hace eso. Existe antes de que el usuario entre y sigue existiendo
cuando se va. No lleva la cuenta de rachas ni de constancia; conserva lo
que la constancia dejó atrás — una esquina gastada, una marca de café —
que es una cosa completamente distinta.

El usuario nunca crea el lugar: el lugar ya existe, y el usuario
simplemente entra.

## 2. Problema que resuelve

El Estudio no resuelve un problema de productividad. Resuelve un problema
de carga mental.

Una vida entera no cabe en una lista de tareas. El problema real no es
"me falta organización" — es que cada pensamiento nuevo obliga a decidir
dónde va, y esa decisión constante es la que cansa. El Estudio existe
para que esa decisión desaparezca: cada pensamiento entra por una sola
puerta y encuentra un hogar sin que el usuario tenga que elegir dónde
guardarlo.

## 3. Filosofía

Principios fundamentales, sin variaciones:

- El Estudio no es una aplicación.
- Es un lugar.
- Cada pensamiento debe encontrar un hogar.
- Los muebles son más importantes que las pantallas.
- La IA recuerda; no enseña.
- Nada desaparece; solo cambia de lugar.

## 6. Descubrimientos importantes

Los hallazgos que cambiaron la dirección del proyecto:

- El usuario no quiere decidir dónde guardar las cosas.
- Cada pensamiento necesita un hogar.
- Los muebles son más importantes que las pantallas.
- Primero se construye el lugar; luego el movimiento.
- Una hoja nunca desaparece; cambia de hogar.
- El objetivo es reducir carga mental, no aumentar productividad.

## 7. Roadmap resumido

**Fase 1** — Lugar habitable
**Fase 2** — Muebles completos
**Fase 3** — Movimiento y sonido
**Fase 4** — IA que comprende

## 8. Cómo debe trabajar cualquier IA en este proyecto

- Reutilizar antes de crear.
- Priorizar bajo consumo de tokens.
- No romper la metáfora del Estudio.
- No agregar funcionalidades porque sí.
- Preguntarse siempre si una solución hace que el Estudio sea más habitable.
- No crear nuevas pantallas cuando pueda crearse un nuevo mueble u objeto.
- Build limpio.
- Lint limpio.
- Declarar limitaciones cuando existan.

## 9. Próximo objetivo

La prioridad hoy no es agregar funciones nuevas. Es que cada mueble sea
lo suficientemente bueno como para reemplazar la herramienta que el
usuario utiliza actualmente:

- Trading debe reemplazar el diario de trading.
- Hábitos debe reemplazar el sistema actual de hábitos.
- Diario debe convertirse en el lugar donde el usuario realmente quiera
  escribir.

Biblioteca y Finanzas vendrán después.

## 10. Lo que El Estudio nunca será

El Estudio no intenta competir con Notion, Obsidian, Apple Notes, Todoist
o cualquier gestor de productividad.

No busca tener más funciones.

Busca reducir la carga mental.

Cuando exista una decisión entre agregar una función nueva o hacer que un
mueble sea más habitable, siempre gana el mueble.

El objetivo nunca es organizar información.

El objetivo es que la mente vuelva a estar disponible para vivir.
